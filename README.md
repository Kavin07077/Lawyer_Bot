# Lawyer_Bot

An AI-powered legal assistant and case management platform built with Python and Flask.

## Features

- **Legal Query Assistance**: Instant legal guidance and IPC section information.
- **Multilingual Support**: Speech-to-text, translation, and text-to-speech for accessible consultations.
- **Role-based Dashboards**: Dedicated portals for users, lawyers, and administrators.
- **Lawyer Consultation**: Connect with verified legal professionals and schedule consultations.

## Tech Stack

- **Backend**: Python, Flask, MySQL
- **AI / NLP**: Groq API, NLTK, SpeechRecognition, Deep-Translator, gTTS
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kavin07077/Lawyer_Bot.git
   cd Lawyer_Bot
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv .venv
   # Windows
   .venv\Scripts\activate
   # Linux / macOS
   source .venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the application:**
   ```bash
   python main.py
   ```
